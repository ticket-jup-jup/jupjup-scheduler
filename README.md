# JupJup Scheduler

공연 정보 동기화, 취소표 확인, 예약 만료처럼 반복 실행이 필요한 작업을 요청하는 애플리케이션입니다.

작업 실행을 요청하는 역할은 스케줄러에 두고, 실제 데이터 처리는 각 API 서버에서 담당하도록 구성했습니다. 스케줄러는 지정된 작업을 요청한 뒤 종료합니다.

> 전체 프로젝트 소개와 아키텍처는 [JupJup 메인 저장소](https://github.com/ticket-jup-jup/jupjup-api)에서 확인할 수 있습니다.

## 주요 작업

| 작업 | 설명 | 요청 대상 |
| --- | --- | --- |
| 공연 정보 동기화 | 프로그램·회차·좌석 정보 갱신 | 줍줍 서버 |
| 취소표 확인 | 구독 중인 회차의 티켓 상태 확인 | 줍줍 서버 |
| 예약 만료 | 결제 기한이 지난 임시 예약 처리 | 줍줍 서버·티켓 서버 |

스케줄러는 실행할 작업에 맞는 API를 호출한 뒤 종료합니다.실제 데이터 조회와 변경은 요청을 받은 서버에서 처리합니다.
